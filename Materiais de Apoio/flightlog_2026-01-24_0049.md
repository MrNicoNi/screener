## Decisões de Engenharia (Black Box)

| Decisão | Contexto/Motivo | Alternativas Descartadas |
| :--- | :--- | :--- |
| JSR em vez de ESM.sh | ESM.sh causava falha de cold start com HTTP 500 | ESM.sh (instável), deno.land/x |
| `--no-verify-jwt` no deploy | Permite OPTIONS preflight passar sem token | Validação continua no código da função |
| Validação manual de JWT na função | Manter segurança mesmo com verify_jwt=false | Confiar apenas no gateway |
| Email não enviado em Dev Mode | Evitar spam durante testes locais | Enviar sempre (risco de spam) |
| SendGrid API direta | Já temos credenciais da empresa | Nodemailer SMTP (mais complexo) |
