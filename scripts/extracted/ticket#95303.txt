Gostaria de informar que a funcionalidade de limitação de acesso de usuários a grupos já está disponível. Para configurar a restrição de

Caixa à esquerda: Lista os grupos restritos ao usuário.
Nota: No exemplo acima, apenas o grupo "Hums" é exibido por ser o único criado para este fim até o momento.
Observação importante: Apenas grupos com a opção "Controle de acesso administrativo" habilitada podem ser utilizados para essa
limitação. Certifique-se de ativar essa função ao criar ou editar um grupo de usuários.

1. Correção das Funções de Acesso
Entendemos que o controle de permissões é um pilar importante de segurança para a sua operação, garantindo que cada usuário acesse
apenas as páginas e informações pertinentes à sua função. Sendo assim, com o apoio da minha gerência, entraremos em contato com a IBM,

Além das permissões de sistema, conversamos sobre a necessidade de restringir o acesso apenas a determinados grupos de
dispositivos. Estou trabalhando para garantir que essa configuração seja funcional em seu ambiente. Retornarei entre segunda e terça-feira
com a confirmação para prosseguirmos com a configuração.
3. Relatórios de Localização para Auditoria
Atualmente, a plataforma gera relatórios de localização individualmente por dispositivo, não havendo um recurso nativo para um relatório
consolidado/geral. Sendo assim, apresentamos as seguintes alternativas:
Uso de APIs (MaaS360): Podemos liberar o acesso às APIs e fornecer as instruções técnicas. Para isso, basta abrir um novo chamado
com o time de suporte. Ressaltamos que o desenvolvimento de scripts ou ferramentas de consumo da API fica sob responsabilidade do
cliente.
Solução Customizada: Caso prefiram uma solução pronta, nossa área de automações pode desenvolver um projeto sob medida para
gerar esses relatórios periódicos. Para orçar este projeto, você pode falar com a Yasmin ou diretamente com o time comercial pelo e-
mail: navita.commercial@enghouse.com.
