Olá Vinicius, boa tarde! Tudo bem?
Em alguns casos para que o web app consiga rodar no aparelho a plataforma solicita o uso do browser do próprio MaaS360. Esse webapp foi distribuído
pelo MaaS360 como um aplicativo gerenciado. Nesse formato, ele precisa abrir através do MaaS360 Secure Browser. No entanto, o Secure Browser não
está instalado ou não está ativo no dispositivo, o que gera a mensagem de erro no momento do acesso.
Abaixo seguem duas opções de solução que pode aplicar em sua plataforma, conforme preferir:
Opção 1 – Utilizar o MaaS360 Secure Browser 
Esta opção mantém o acesso ao webapp dentro do ambiente protegido do MaaS360, basta distribui o app  da IBM ''MaaS360 Secure Browser'' que serve
exatamente para esses casos.
Passo a passo:
Publicar o aplicativo “MaaS360 Secure Browser” pelo catálogo de apps, na opção Android > Google Play Store
Garantir que o app seja distribuído para os mesmos dispositivos
Adicione o app nos aplicativos liberados dentro das configurações do modo quiosque, através da aba de design na opção ''Kiosk Experience
Designer''
Forçar a sincronização do dispositivo
Após isso, o ícone do MaaS360 Browser aparecerá no aparelho e o webapp abrirá normalmente
Opção 2 – Abrir o webapp no navegador padrão do aparelho
Esta opção elimina a necessidade do Secure Browser, utilizando o Chrome (Android) ou navegador padrão.
Passo a passo:
Remover o webapp atual
Criar novamente o webapp no MaaS360 sem configuração de aplicativo seguro/gerenciado
Publicar o novo webapp para o dispositivo
Forçar a sincronização
O acesso passará a ser feito diretamente pelo navegador padrão
Ficamos à disposição para aplicar a opção mais adequada conforme a necessidade de segurança do ambiente.

aparelho, por questões de fluxo de atendimento realizamos as tratativas uma por vez, em chamados separados!

Olá Vinicius, boa tarde! Tudo bem?
Conforme sua dúvida sobre a opção “Adicionar à tela inicial” ao acessar o site www.manusys.com.br, o comportamento que você descreveu no Chrome
acontece porque o navegador cria um atalho/atalho de Web App (PWA) no dispositivo — isso é algo criado localmente pelo próprio Chrome quando o site
oferece essa opção.
Entretanto, neste contexto — com dispositivos Device Owner e modo quiosque gerenciado pelo MaaS360 — não é possível liberar esse atalho que os
usuários criam manualmente diretamente no quiosque, pois ele não é um aplicativo que o MaaS360 reconhece ou gerencia por padrão.
Criar um Web App no MaaS360:
No console MaaS360, vá em Apps > App Catalog.
Escolha a opção de Web App (Android).
Preencha os dados com:
Nome: (Ex.: Manusys Web App)
URL: https://www.manusys.com.br
Ícone e nome visual que desejar usar.
Salve e publique esse Web App.
Incluir o Web App no qui​osque:
Vá em Android > Quiosque (Multi-App Kiosk).
Adicione o Web App criado à lista de apps permitidos no quiosque.
Ajuste as políticas se necessário (ex.: bloquear Chrome “completo”, permitir apenas o Web App).
Valide e nos retorne!
